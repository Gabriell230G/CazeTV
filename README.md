## 💡 A ideia

A CazéTV é o **maior canal de esporte do YouTube no Brasil** (40M+ inscritos) e, mesmo detendo os direitos digitais da Copa 2026, **não tem site próprio**. Isso gera três brechas:

- 🔎 Quem busca *"camisa Cazé TV"* no Google cai em **réplica**, não no oficial.
- 🛒 A loja vive só dentro do Mercado Livre — sem experiência de marca, sem *drop*.
- 📺 Não existe um lugar que junte **onde assistir + loja + quem faz a Cazé**.

Este projeto imagina essa casa digital — do zero.

## ✨ Destaques

| | |
|---|---|
| 🎨 **Brand-native** | Identidade real: dourado, preto e o mascote. |
| 🛍️ **Loja / Drops** | 5 produtos com **fotos e preços reais**, levando ao checkout oficial. |
| 📅 **Agenda ao vivo** | Do campeão da Copa ao Brasileirão. |
| 🎬 **Assista mais** | Melhores momentos reais do canal + todos os canais oficiais. |
| ⭐ **Elenco completo** | 30 integrantes com **perfil clicável** e trajetória de cada um. |
| 🌍 **Trilíngue** | Seletor **PT / EN / ES** que traduz o site inteiro, inclusive as bios. |
| 🌗 **Tema claro/escuro** | Com preferência salva no navegador. |
| ⚡ **Animado & mobile-first** | Contadores, reveal no scroll, hovers e microinterações. |

## 🛠️ Tecnologias

- **HTML5** semântico
- **CSS3** puro — variáveis de tema, grid/flex, animações (sem framework)
- **JavaScript** vanilla — `IntersectionObserver`, i18n, tema, contadores
- **Font Awesome** + **Google Fonts** (Anton / Inter / Fredoka)
- **Zero build** — é só abrir

## 📁 Estrutura

```
CazeTV_Site/
├── index.html        # marcação
├── css/
│   └── style.css     # estilos + temas
└── js/
    └── main.js       # i18n, tema, animações, perfis do elenco
```

## 🚀 Como rodar

```bash
# 1. clone o repositório
git clone https://github.com/<seu-usuario>/CazeTV_Site.git

# 2. abra o index.html no navegador
#    (ou sirva localmente)
npx serve CazeTV_Site
```

> 💡 **GitHub Pages:** Settings → Pages → Branch `main` /root → o site fica no ar em `https://<seu-usuario>.github.io/CazeTV_Site/`.

## ⚠️ Aviso

Projeto **conceito, não-oficial**, criado como peça de portfólio. **Sem vínculo** com a CazéTV / LiveMode. Produtos, preços, números e agenda são reais (jul/2026) e usados apenas para demonstração. Marcas de terceiros pertencem aos seus donos.
